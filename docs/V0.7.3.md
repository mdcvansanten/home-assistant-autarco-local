# Autarco Local v0.7.3 — SOC jump/drop monitoring

v0.7.3 extends the v0.7.2 field-test dashboard with read-only battery SOC anomaly monitoring.

## SOC jump/drop detector

- Observes consecutive successful runtime polls of battery SOC register 33139.
- Flags an abrupt change of 5 percentage points or more within 180 seconds.
- Classifies the event as `jump` or `drop`.
- Captures from/to SOC, delta, elapsed time and battery power at detection.
- Fires Home Assistant event `autarco_local_soc_anomaly` for optional automations/notifications.
- Adds a diagnostic sensor `SOC jump/drop monitor` so Recorder can retain state/history.
- Stores the latest in-memory event details in sensor attributes and diagnostics.

The detector deliberately ignores changes across gaps longer than 180 seconds to reduce false positives after outages/restarts.

## Dashboard visualisation

When Battery SOC is selected in the History tab:

- SOC jumps are shown as green markers on the SOC graph.
- SOC drops are shown as red markers.
- A jump/drop event panel lists the latest events with timestamp, delta and battery power.

The in-memory detailed event list starts fresh after Home Assistant restarts. The diagnostic sensor and Home Assistant event can be recorded/automated independently.

## Safety

This release adds no new inverter writes. Existing v0.6.6 write safety remains unchanged.

## Network field test

For the current LAN-stick field test, keep Autarco Local itself connected to the Ethernet Modbus endpoint and monitor Ethernet and Wi-Fi independently with Home Assistant Ping entities. This keeps connection diagnosis separate from automatic failover while both interfaces are being evaluated.
